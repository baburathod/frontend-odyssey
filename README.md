## 📖 Project Description

**"The Life of a Developer"** is a humorous, scroll-driven interactive storytelling experience that takes the viewer through **6 chapters** of every developer's relatable journey — from typing their first `Hello World` to surviving production outages at 3AM.

The experience is designed to feel like an **Awwwards-style narrative website** — where every scroll reveals a new chapter, animation, and moment from the developer life. Equal parts funny and technically polished.

> *"From `<h1>Hello World</h1>` to production outages at 3AM"*

## ✨ Features

### 🎯 Mandatory Requirements ✅
- [x] **5+ Story Sections** — 6 cohesive narrative chapters
- [x] **Scroll-Based Interactions** — Parallax, sticky coffee meter, scroll-triggered reveals
- [x] **3+ Interactive Elements** — Hover cards, tag effects, nav links, buttons
- [x] **3+ Animations** — 8 distinct CSS animations + GSAP timelines
- [x] **Responsive Design** — Mobile, tablet & desktop fully supported

### 🏆 Bonus Features
- [x] **Three.js Particle Background** — color shifts per section on scroll
- [x] **GSAP Animated Counters** — live counting stats in Debugging section
- [x] **Lottie Loading Screen** — animated spinner with progress bar
- [x] **CSS Glitch Effect** — on hero title
- [x] **Scroll Progress Bar** — top of page
- [x] **Live Ticker Banner** — scrolling dev jokes
- [x] **Coffee Meter** — fills up as you scroll through Deadlines section

## 📚 Story Structure

```
Chapter 01 → Learning HTML      (The naive phase)
Chapter 02 → The Debugging Era  (Stack Overflow life)
Chapter 03 → Deadlines & Coffee (The real developer experience)
Chapter 04 → The Wisdom         (What you actually learn)
Chapter 05 → Conclusion         (Welcome to the guild)
```
